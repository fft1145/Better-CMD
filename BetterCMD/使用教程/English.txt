Please open the bcmd prerequisite file in the main directory before launching bcmd.exe, the main body of Better CMD!!!

Directories are as follows:
Prerequisite file -> bcmd_prerequisite_files.exe
Main file -> bcmd.exe
Key file -> miyao.txt (generated by the prerequisite file)
Log file -> log\bcmd.log (asked at startup whether to save)

**You must** run the prerequisite file first!!! Otherwise, you will not get the key!!! The key is randomly generated, and I do not know it either. My master key only works under my IP address. The key is stored on the server‑side, so do not attempt to unpack the files blindly.
